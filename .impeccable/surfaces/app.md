# Surface: Speedrundle app (onboarding, picker, dashboard, run mode)

Mode: Operate. Build path: code-led (app screens; no image generation on this machine).
Audience: the owner + friends, phone-first, morning puzzle ritual. Task: start a run in one tap, confirm each game, see if they beat their PB.

## Direction contract
THESIS: Your morning puzzles as a speedrun you can hold: every run is a strip of candy-coloured split blocks. Refuses the grey stopwatch app and the generic SaaS stat-tile dashboard.
OWN-WORLD: (user-pinned) Cream #FFF8EE ground, plum #2B1B3D ink, six pastels with one per game (mint, peach, lavender, butter, baby blue, pink), 3px plum outlines, 4px hard offset plum shadows that press flat on tap like sticker buttons, generous radius (18–28px). Fredoka for display and timer digits (tabular), Nunito for body. A small original mascot (a stopwatch creature).
STORY: The visitor sees their games as colourful stickers, taps one big button, and the strip fills block by block as each game is done. At the end a gold block marks any new best and confetti pops.
FIRST VIEWPORT: Dashboard on a phone. A slim top bar has the wordmark and a settings link. A huge "Start today's run" sticker button sits under a one-line today status. Below it is the last run's split strip at full width, then a 2-column grid: streak, PB for this game set, and sum of best. The 14-day stacked strip chart and the splits table follow.
FORM: Pinned by the user, so no concept roll ran. The user specified "Light mode only, pastel and playful: soft mint, peach, lavender, butter yellow, baby blue, pink. Rounded cards…", then chose the "Candy shop" palette (cream #FFF8EE, plum #2B1B3D, 3px plum border, 4px offset shadow) and approved the first build with "Love it, keep going". That approval stands in for the seed key. The signature move is the split strip, reused in run mode, results, history and the chart's stacked bars.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
